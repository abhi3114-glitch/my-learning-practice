# Jira

Jira is a project management tool for agile teams.

## Key Concepts
- **Projects**: Container for issues
- **Issues**: Tasks, bugs, stories
- **Sprints**: Time-boxed iterations
- **Boards**: Kanban or Scrum views
- **Epics**: Large features

## Workflow
1. Create issues in backlog
2. Prioritize and estimate
3. Plan sprint
4. Move issues through columns
5. Review and retrospective
